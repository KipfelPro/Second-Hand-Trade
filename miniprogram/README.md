# 同窗集

天大专属闲置流转平台。原生微信小程序，包含 19 个页面、4 个公共组件和一套可重置的本地演示数据。

## 导入微信开发者工具

1. 解压源码包，或直接使用当前工作区。在微信开发者工具选择「小程序 → 导入项目」，选择含 `app.json` 和 `project.config.json` 的目录。
2. AppID 选择「测试号」用于本地预览，或填入自己的小程序 AppID。选择当前稳定基础库，点击「编译」。
3. 启动页后进入校园身份认证。点击「去认证 → 自动填入 → 核验身份 → 确认身份」。也可先点「先逛逛」体验访客权限。

演示账号为 `tju-demo`，密码为 `demo2026`。点击「自动填入」即可使用演示凭据。

项目无需安装 npm 依赖。发布页可选样图体验预填，已用于在售商品的照片会从样图候选中隐藏。上传自己的照片时，棠小助提供可编辑的描述模板，名称、价格、成色等由用户填写。录音如因设备或权限无法使用，仍可编辑示例转写文字。

## 演示路径

| 路径 | 操作 |
| --- | --- |
| 认证和浏览 | 先以访客查看商品。点击下单、私聊或发布时进入模拟认证。核对回传的脱敏学籍后继续。 |
| 智能搜索和推荐 | 在首页切换卫津路或北洋园，再浏览商品或输入「大一上高数教材」。分类页提供全校、卫津路校区、北洋园校区和同学院四个范围，商品品类含「其他」。 |
| 求购和撮合 | 打开「发布求购」，或对棠小助说「求购轻微使用的宿舍小冰箱，预算 150 元」。核对表单后发布，在「我的求购」查看匹配和模拟卖家通知结果。 |
| 单件发布 | 在首页选好面交校区，再到「发闲置」选择一张样图。预填后修改成色、价格、描述等字段，并从该校区的公共地点中选择自提点。 |
| 批量发布 | 打开批量发布，使用多张样图生成草稿。设置统一成色、价格范围和地点，打开一条草稿修改并返回，最后一键发布。 |
| 买家私聊 | 打开「消息 → 私聊 → 我买的」，或者从商品页联系卖家。商定价格、自提点和时间，再从聊天下单。预约与议价会同步到订单。 |
| 卖家私聊 | 打开「消息 → 私聊 → 我卖的」。可回复买家、接受预约或提出改期，面交后登记交付并模拟买家确认收货。 |
| 改约和售后 | 待面交订单可从「联系卖家」发起改约，也可申请售后并模拟审核。 |
| 棠小助 | 棠小助在屏幕右侧中段待机，可拖动。她会翻滚、转身和回弹，点开面板可喂花蜜，长按可摸头。 |

「我的 → 设置 → 减少动态效果」可降低登录插画、首页校区切换、订单进度和棠小助的动效。「重置演示数据」可恢复首次启动状态。

## 校园数据来源

- 院系名称以官网「学院（部）」目录为准，用于演示学籍、卖家资料和推荐。分类页只提供校区和同学院范围。示例账号认证后，学院、校区及模拟住宿资料保存在当前设备，用于优先推荐同楼、同院、同校区商品。实际教学地点可随专业和年级变化。 [学院（部）目录](https://www.tju.edu.cn/xy_b_.htm) · [2026 年研招院系联系表](https://yzb.tju.edu.cn/xwzx/zxxx/202603/t20260317_324570.htm) · [2026 届毕业生招聘指南](https://job.tju.edu.cn/Uploads/file/20250903/1756863521860323.pdf)
- 自提点统一为「校区全称＋地点」，例如「卫津路校区科学图书馆门口」和「北洋园校区郑东图书馆门口」。单件和批量发布使用对应校区的公共地点列表。升级时，旧的用户发布保留原地点文字并补齐校区格式，编辑时可重新选择。 [卫津路校区导览](https://fw.tju.edu.cn/Weijin.html) · [天津大学图书馆](https://www.tju.edu.cn/info/1046/1302.htm) · [天津大学场馆中心](https://www.tju.edu.cn/info/1046/1285.htm) · [天津大学迎新网食堂信息](https://yx.tju.edu.cn/jztd/ys/201806/t20180602_307309.htm)
- 表单、分段控制和弹层交互参考微信 WeUI 与 TDesign，宠物动效使用正视图、侧视图和 WXSS 关键帧。首页轮播每 3.2 秒换图，也可点横幅底部的分页圆点切换。 [WeUI for 小程序](https://github.com/wechat-miniprogram/weui-miniprogram) · [TDesign 小程序组件库](https://github.com/Tencent/tdesign-miniprogram)

## 实现范围

门户身份、支付托管、售后审核、卖家回复和通知均在本地模拟。门户核验仅在页面内处理演示凭据，确认后持久化的是脱敏身份。棠小助使用词表、规则排序、内置图片样本和示例转写处理需求，录音不上传。近邻排序按模拟楼栋和学院处理。

登录页中的建筑是参考校园地标生成的插画。商品、人物和住宿分配为演示数据，商品照片为 AI 生成的示意图。

首次打开或从旧版升级时会载入新版示例目录。升级会从在售列表撤下旧示例中的重复商品。对同一卖家、同名、同封面的多条在售商品，展示保留一条；旧私聊和订单仍可打开原记录。

界面尺寸采用 750rpx 适配基准，固定操作区处理底部安全区。微信设计链接未能直接访问，rpx 单位参考了腾讯云小程序开发指南。Gitee 参考项目未能读取，登录、库存、订单和私聊按需求独立实现。 [腾讯云小程序平台开发指南](https://main.qcloudimg.com/raw/document/product/pdf/1593_91178_cn.pdf)

使用微信开发者工具编译器检查 WXML 和 WXSS，使用本地 Mock 检查双校区筛选、发布校验、旧数据迁移及交易流程。真机效果可在微信开发者工具中点击「预览」扫码查看。
